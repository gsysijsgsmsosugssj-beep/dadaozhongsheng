# 扫完码别急着点「允许」：手机端确认页多出来的那一行字，往往就是假入口的破绽（6 项字段 + 6 格对照）

上周四快十二点，小许把手机推到我面前，屏幕上已经是一张确认登录的卡片了。设备行写着 Windows · Chrome，城市是本市的，时间和她刚扫的那一下对得上，两个按钮一左一右，跟过去每一次都长得差不多。她说，就是这个吧，点允许？

我没接话，把手机扣在桌上。卡片底部多了一行字，大意是"为完成验证，请在下方填写你的两步验证密码"。官方那张卡片上没有这一行，一次都没有过。她扫的码来自群里转的一个"网页版加速入口"，码本身是货真价实的登录码，只是 token 先落到了别人手里，再被画成一张新码递给她。

那晚我们把她的会话翻了一遍，踢掉两台不认识的设备，改了两步验证。她后来问我一句：那么像，你怎么看出来的。这篇就把"怎么看"写清楚——只看手机上那一块屏。电脑端的二维码怎么出、扫不出来怎么查，站上 👉 [Telegram网页版中文指南](https://tlgrqo-web.com) 的扫码流程已经写得比我细，这里不再重复。

## 一、这一屏的字段是可数的：六项，一项不多

确认页不是"感觉对不对"的问题，它有固定字段。把它当成一张要核对的表单，逐格看就行。

| 该有的字段 | 正常写法 | 被仿时常见的走样 | 我的判据 |
| --- | --- | --- | --- |
| 设备行 | `Windows · Chrome`，中间一个居中点 | 写成"未知设备""浏览器"（不写名字）、拆成两行 | 系统和浏览器名缺一个，先存疑 |
| 城市 | 城市名，可能带国家名 | "未知位置"，或与你所在地毫无关系 | 城市只是参考值，但"未知"不是正常值 |
| IP 地址 | 新版本会给出一串 IPv4 | 写成域名，或 127.0.0.1 这类本地地址 | 出现域名的一律不对劲 |
| 时间 | 你按下扫码的那一分钟 | 时间对不上，或干脆不写 | 这一项最好核 |
| 动作按钮 | 两个：允许登录 / 拒绝 | 多出"取消""稍后""继续"第三键 | 两键就是两键 |
| 说明句 | 一句短语，说清这台设备能做什么 | 要求输入密码、验证码、手机号后四位 | 确认页不收集任何凭证 |

六行里只要有一行不对，整张卡片就不必再看下去。小许那晚撞的是第六行——她那张卡片不但要密码，还贴心地给你做了一个输入框。

## 二、"多出来的那一行"通常有三种来路

### 第一种：第三方客户端自造的文案

汉化包、第三方客户端、所谓增强版，会把登录确认这一屏重画一遍。它们多半是真在替你做登录，文案却多出一截，比如"同步最近 30 天消息""开启云端加速"。这类不一定是骗，但它一定不在官方流程里，而你已经没法凭记忆分辨哪句是官方的。判据很硬：**官方卡片上的每一句，都能在另一台正版设备上复现**。复现不了，就是加的。

### 第二种：浏览器页面里画出来的"确认页"

这一种最容易骗过人，因为它的排版可以做得比官方还工整。要记住一条硬边界：**确认页只存在于 Telegram App 内部**。你在浏览器标签页里看到的任何"请在手机上确认""请在此输入验证码"，都不是 Telegram 的东西——它连"仿"都算不上，是另一套东西借了这张脸。我见过最像的一版，把手机边框、状态栏电量、时间全都画进去了，唯一露馅的地方是那格电量图标不会动。

### 第三种：真码被转手

码是真的，脸是真的，只有中间那一段不是你。有人把登录 token 转给第三方，再生成一张新码给你扫，你在手机上确认的其实是**他那台机器**，卡片上的城市和 IP 恰好是他那边的出口。这种情况字段全对，只能靠"我这张码是从哪来的"来挡。

## 三、截图级对照：六格，一格一格看

这张卡片在手机上停留不过十几秒，看不了太细。按下面这个顺序扫一眼，五秒够用：

1. **看标题行**。中文界面是"登录到 Telegram 网页版"或"确认登录"，英文界面是 `Sign in to Telegram Web`。标题被换成"安全验证""账号保护""身份核验"的，停在这里，别往下走。
2. **看设备行的连接符**。官方是系统名、一个居中点、浏览器名，三段不换行。写成 `Windows/Chrome`、拆成两行、字号还忽大忽小的，是重画的。
3. **看按钮**。右侧是实心的"允许登录"，左侧是弱化的"拒绝"，就两个。出现第三个按钮，或者"允许"被写成"继续""确认身份"，停。
4. **数输入框**。零个。这一屏没有任何需要你打字的地方。看到密码框、验证码格子、手机号后四位，直接按返回。
5. **试一次"拒绝"**。点下去卡片应该立刻消失，不追问、不弹二次确认。点了没反应，或者跳去了浏览器，问题比仿站还大。
6. **回电脑看结果**。拒绝之后，电脑上应该一直停在"等待确认"，直到码自己过期，报错文案通常是"登录请求已过期，请重新扫描二维码"。电脑上却已经进去了 —— 说明你确认的根本不是它。

## 四、三个会让人误判的版本差异

**旧版客户端少两行。** 大约 2021 年前的安卓版本，卡片只写城市，不写浏览器名和 IP。手上是这种老版本时，别把"没写设备"直接当假——先升级，再判断。

**网页版两套前端不一样。** 二维码页面右下角可以在 WebK 和 WebA 之间切换，两套的过期提示和刷新节奏不同，一套自动重载，一套要手动点一下。卡住的时候换一套试试，比反复扫有用。

**清站点数据能验真伪。** Chrome 里点地址栏左侧的图标 → 网站设置 → 删除数据；或者走 设置 → 隐私和安全 → 网站设置 → 查看权限，找到这个站点清掉。真正的登录页清完会给一张新码；如果清完还是原来那张码，页面就是缓存下来的仿页。Edge 在 设置 → Cookie 和网站权限 里做的是同一件事。

## 五、确定不对劲之后，按这个顺序处置

1. **先在手机上点"拒绝"。** 别只是把电脑上的标签页关了，那不等于拒绝。
2. **进 设置 → 设备，逐条看活跃会话。** 认不出的直接终止，留意每条下面的"最近活动"时间和地点。
3. **改两步验证密码。** 设置 → 隐私和安全 → 两步验证，顺手把恢复邮箱核对一遍。站上 [设备与会话管理](https://tlgrqo-web.com) 那一节把入口写得更细。
4. **如果已经误点了允许**：立刻在设备列表里终止那一条，再改密码，然后把"自动下载媒体"关掉——对方在你号里待过的那几分钟，能拿走的东西比你以为的多。
5. **记下这张码的来路。** 哪个群、哪条短链、哪张图。下一次它换个皮还会来。

## 六、日常防伪清单

- 码只从自己敲地址或收藏夹打开的那一页出，群里转的一律不出码。
- 手机确认页出现输入框，退回，不看第二眼。
- 卡片上多出一句你没见过的说明，按假的处理，哪怕其它字段全对。
- 确认前扫一眼城市和 IP；对不上就先点拒绝，回电脑重扫一次，别硬确认。
- 借别人电脑登过之后，走之前用"退出登录"，不是关标签页；退出后再清一次该站点的 Cookie。

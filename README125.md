# 成品号、老号、小号怎么选：货架前删了四次购物车，我把它拆成七个「如果→则」

上周三夜里十一点四十，我在 [TG账号商城](https://tlgrpv-hao.com) 的货架前站了半小时，购物车里那个 25.9 元的成品号加了又删、删了又加，前后四次。两次是嫌 68 元的老号太贵，两次是觉得 6.9 元的小号更像"会算账的人"该做的选择。页面右下角一直挂着"1,284 单"，我盯着那个数字发愣：这么多人下得去手，怎么到我这儿就卡住了。

关了页面也没睡着，翻了张便签，把三个价格改写成三个问题：这个号要不要露脸、要不要带过去、要不要成批交。写完发现七行就够，再多一行都是自我安慰。第二天照那七行下单，付款到出号 18 秒，比我前一晚纠结的三十分钟短得多。

这篇就是那张便签的抄本。

## 一、三个号不是三个价位，是三种完成度

把"成品号 25.9 / 老号 68 / 小号 6.9"当成价格梯度去比，怎么算都别扭——因为这三个数字压根不在同一根轴上。它们真正的差别是三个变量：

- **完成度**：拿到手能不能直接登进去干活。成品号是"已注册 + 已激活双因素 + 支持改绑邮箱与设备"，一步到位；小号是"账号密码成表"，你得自己一个个往里塞。
- **过去**：这个号有没有可追溯的行为史。老号三年以上的聊天、群组、频道订阅是连续散在时间线里的，这是它抗举报的底子；另外两档的"过去"是空白。
- **起订量**：一次最少买几个。这是最容易被页面价签骗过去的一格。

这三格一摆，购物车里的东西就不叫"三个价位的同一种商品"了，而是耗材、工具、身份三种物件。你去五金店不会拿一卷胶带和一把电钻比单价。

## 二、决策树第一层只有一个问题：这个号要不要露脸

"露脸"别理解成抽象概念，落到操作上很具体：头像点得开、简介有人看、用户名会被陌生人搜到、这个号要占在别人的对话列表里一行。

**如果是**——这个号要替你说"我是谁"，只能往老号走。三年以上的活跃记录意味着系统侧看它是真人，也意味着你进同行群做自我介绍时，别人点进主页看到的不是一个上周才出生的空壳。这一步省不掉。

**如果不是**——号只在你手里干活，往下走第二层：它干的是"要回话的活"还是"只走量的活"。

**如果它根本不打算被谁记住**——直接跳小号分支，别在上面两层浪费时间。

货架上有两个数字可以帮你判断第一层。老号卡片写"现货 36"，这是真库存，卖完自动下架；成品号写"火爆现货 99+"，是打包口径的区间。真库存敢写死，说明它不打算无限接单，这种标法比"永久现货"可信。

## 三、七条「如果→则」，照抄那张便签

1. **如果只是订阅频道、看资讯、偶尔私聊朋友** → 25.9 元成品号 1 个，登进去改密码、绑邮箱、踢掉陌生设备就完事，别加任何一档。
2. **如果要拿这个身份谈生意、挂店名、进群自我介绍** → 68 元老号 1 个当门面，再配 1 个成品号跑腿，两副手套分工。
3. **如果要做矩阵、批量测通道、跑活动通知** → 6.9 元小号，但账要先算对：10 个起，一次最低 69 元，比一个成品号贵近三倍。
4. **如果三种活同时存在** → 一老一成品一小包，68 + 25.9 + 69 = 162.9 元，够一个两三人小组转起来。
5. **如果预算卡在三十块以内** → 老老实实买成品号。别把这三十块拆成"三个小号试试水"，起批量会把你的算盘直接掀了。
6. **如果是替别人买、或者几个人共用** → 至少两个成品号。换号要凭订单号，一个人拿一部手机管三个号的验证码，出事时你分不清是哪个卡住了。
7. **如果还没想清楚用多久** → 先一个成品号跑满一周，看它在你常用的线路上会不会被限流，再决定要不要升到老号。

七条看完，那半小时的纠结其实只剩第一条和第二条之间的选择。

## 五、走到老号分支，头一件事是把陌生人清掉

老号的价值在历史，麻烦也在历史。登进去按这个顺序做四步：

1. 设置 → 隐私和安全 → 设备，页面里那一串"活跃会话"逐个看，不认识的直接"终止其它所有会话"。
2. 两步验证开起来，绑自己的邮箱——别用卖家随号给的那个。
3. 通讯录和私聊列表翻一遍再决定删不删。有些是原号主的客户，你留着，对方来一句"上次那批货呢"，你回什么都露馅。
4. 用户名先别改，简介先空着，养一周再动。改得越早，越像刚被人接手。

**报错文案记一下**：连续操作太快，客户端会弹 `Too Many Requests: FLOOD_WAIT_86400`，括号里是秒数，86400 就是一天。这是限速不是封号，别卸载重装、别换设备重登——那只会再叠一层，把一天变成两天。

## 六、走到小号分支，十个号别塞进一条宽带

"独立 IP 注册"这四个字，只保证注册那一步是干净的。你把十个号全从家里那条线上登一遍，等于亲手把独立 IP 抹平，白花钱。

分批登，一次 3 到 5 个，中间隔开几个小时；分环境，手机分身、多开器、独立的浏览器配置都行，别共用同一个；别同分钟操作，十个号同一秒加同一个群，群管理扫一眼名单就看出来了。

限额也得心里有数：小号 10 个起，要五十个得分五批交付；新号一天加十几个群就开始回 `FLOOD_WAIT_86`（86 秒），再猛一点直接给你 `FLOOD_WAIT_43200`（12 小时）。

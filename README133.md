# 网页版少的那 8 个功能：手机端独有的东西在浏览器里怎么补，一张差异表配 6 个替代动作

上周帮一个做外贸的姑娘远程，她要在电脑上给客户开一段"只有对方能看、看完自动销毁"的对话。我在电话这头听她把左侧栏从上滚到下，又把每个聊天的右键菜单点了个遍，中途还去设置里翻了两圈，末了憋出一句："是不是我版本太旧了？"

不是版本旧。是**秘密聊天在网页版里根本不存在**，它不是被折叠进了某个二级菜单，而是压根没做。这类"翻遍界面找不到"的情况，我一个月能遇上四五次，共同点是：大家默认网页版是手机端的缩小版，功能应该一一对应。实际不是。

这篇只讲一件事：**网页版与手机端的功能差在哪里、缺的那些怎么用别的动作补上**。差异清单我整理成了表，替代动作按顺序排好了，照着做就行。更细的界面截图在 [Telegram网页版中文指南](https://tlgrwo-web.com) 上，边看边对更省事。

## 它为什么天生少一截，这不是 bug

浏览器是个沙箱。它拿不到你手机里的通讯录，拿不到设备的安全芯片，也没法在后台长期持有一个加密会话的密钥。所以 Telegram 网页端（不管是 WebK 还是 WebA 那两套实现）在功能上做的是**减法**，删掉的恰恰是依赖系统权限和本地密钥的那部分。

想明白这一层，找功能的方式就得改：**先在脑子里过一遍"这个动作要不要碰系统权限或私钥"，要碰的，别在浏览器里找。** 找不到不是你没找对，是它不在那儿。

## 一张表看完：缺哪些、卡在哪、拿什么顶

| 功能 | 手机端在哪 | 网页端现状 | 替代动作 |
| --- | --- | --- | --- |
| 秘密聊天（端到端加密） | 新建聊天时选"秘密聊天" | 完全没有入口，也看不到别人发起的秘密会话 | 这类对话一律回手机处理；网页端只做普通聊天的归档 |
| 动态 / Stories | 底部或顶部"动态"栏 | 无，别人的动态也刷不到 | 让对方把内容发成频道帖子或直接私聊发图 |
| 实时位置共享 | 附件 → 位置 → 共享实时位置 | 只能看别人发来的位置，自己发不了实时 | 发一次静态位置 + 一句"我在这附近，到了喊你" |
| 通讯录同步与邀请 | 设置 → 隐私和安全 → 联系人或"邀请朋友" | 读不到手机通讯录，也没有同步入口 | 手机端生成邀请链接，复制到网页端粘给同事 |
| Mini App（机器人小程序） | 聊天里点机器人按钮直接开 | 点了弹一行灰字，大意"该功能在网页版不可用" | 把 `t.me/机器人名?start=参数` 粘到新标签页，用浏览器单独打开 |
| 每个聊天单独设壁纸 / 编辑主题 | 聊天设置 → 更换壁纸；设置 → 聊天设置 → 创建主题 | 只有全局预设，不能编辑 | 网页端别折腾外观，把时间放在搜索和文件上 |
| 内置代理设置 | 设置 → 数据和存储 → 代理 | 没有代理入口，只能跟随系统和浏览器 | Chrome 用启动参数或代理扩展，系统层设全局代理 |
| 自动下载与流量控制 | 设置 → 数据和存储 → 自动下载 | 无此设置项 | 好处是不会偷跑流量；代价是点开就下到默认目录，得自己管 |

表里八项，前四行属于"回手机"，后四行属于"换条路走"。分清楚这两类，效率差很多。

## 按表办事：六个替代动作，顺序别乱

1. **先盘一次你真正缺的**。打开网页版设置，走一遍 `Settings → Privacy and Security → Devices`（中文界面是"设置 → 隐私与安全 → 设备"），把当前登录的设备列表看清楚。这一步的作用是划边界：哪些账号动作只能在手机上确认，心里先有数。
2. **把"授权类"动作全部交给手机**。扫码确认、踢掉陌生设备、开两步验证、改绑邮箱，这四个动作在网页端要么做不全，要么做了不生效。设备列表里看到不认识的一条，点进去选 `Terminate Session`，这一步在哪台设备上点都算数。
3. **Mini App 走浏览器独立标签**。从聊天里长按或右键复制机器人链接，形如 `t.me/某机器人?start=abc123`，前面补上 `https://`，粘到新标签页回车。微信/支付宝这类"必须原生才能调起"的能力它照样没有，但表单填写、查询类的小程序基本能跑。
4. **位置用静态点代替实时流**。附件里选"位置"，点一次发送当前坐标，再补一句文字说明。实时共享的价值在于对方能看到你在动，静态点只能看到你在哪——出差接人这种场景够用，跑长途就不够。
5. **通讯录用邀请链接绕过去**。手机端"邀请朋友"生成的链接，复制到网页版发给自己（Saved Messages），以后直接从这条消息里取。网页端确实读不到通讯录，但链接是文本，文本在哪儿都能传。
6. **代理在浏览器层解决**。网页端没有代理开关，别在设置里翻。Chrome 加启动参数 `--proxy-server="socks5://127.0.0.1:1080"`，或者装个代理扩展按站点分流；Edge 走系统代理，设置 → 系统和性能 → 打开计算机的代理设置。配完回来刷新页面，二维码或聊天列表能出来就说明通了。

## 三个容易被当成"故障"的细节

**第一个是那句灰字。** 在网页端点开某些机器人的按钮，页面底部会滑出一行提示，英文界面写的是 `This feature is not available in the web version`，中文界面大意是"该功能在网页版不可用"。看到它不是网络问题，也不是你没登录，直接按上面第 3 步换标签页开。

**第二个是外观设置的天花板。** 网页端的主题只有预设几套，找不到"创建主题"的入口是正常的——那个编辑器只在手机端和桌面客户端里有。同理，给单个聊天换壁纸这件事网页端做不了，别花时间找。

**第三个是入口真伪，这个比功能差异重要得多。** 有人把"网页版功能不全"当成换站的借口，随手点了群里转的链接，结果进的是仿站。判断方法很简单：点地址栏左侧的锁图标 → 连接安全 → 证书，看"使用者"里 SAN 列出的域名是不是你地址栏里那个，再看"颁发者"是不是能认出来的公共 CA。仿站的两个典型特征——域名比你记的多一级或用连字符拼（`tlgrwo-web.com` 和 `tlgrwo-web-login.com` 完全是两个站），证书里塞了一串不相关域名。功能少可以忍，入口错不能忍。

## 反过来看：这几件事网页版比手机端顺

也别把网页版当残疾版本用。同一份聊天记录，在浏览器里的检索效率高得多：`Ctrl + F` 在当前聊天里搜关键词，全局搜索能按"链接""文件""语音"分类筛；几十个文件直接框选拖进输入框上传，比在手机上一个个点选快。做客服值班、整理群资料、把群里的 PDF 批量存下来，这些活我都只开网页版。

站点的 [浏览器使用建议](https://tlgrwo-web.com) 那几页把标签页、权限、下载目录分开写了，配合这篇的差异表看，思路就完整了：**能力缺口看表，浏览器层面的问题看那几页。**

## 把该回手机的活儿，干脆交回手机

这张表的用法不是让你背下来，而是贴在显示器边上，遇到"怎么找都找不到"的时候扫一眼，确认它属于"没有"还是"有但坏了"。

属于"没有"的——秘密聊天、动态、实时位置、通讯录同步——回手机，三十秒的事，别在浏览器里耗二十分钟。属于"有但坏了"的——二维码不显示、文件下不下来、通知不弹——那才是浏览器的问题，清缓存、关扩展、查权限，三步之内多半能定位。

网页版的身份始终是"另一台登录设备"，不是另一个 Telegram。认下这一点，你会发现自己少了很多无谓的寻找，也少了几次因为急躁而点错入口的机会。

# TG账号登录后的第一小时：我掐着表做完9个动作，五个营销群一个没剩（附Telegram设置路径与两步验证四个字段）

登进去十分钟，号已经被拉进五个营销群。

屏幕顶部一条接一条地弹横幅，群名里三个带「福利」「空投」「资源对接」，第四个是纯数字编号，第五个群主直接 @ 我，问「兄弟要不要了解一下」。这个号是我十分钟前从订单页复制出来的，密码没改，两步验证还挂着卖家设的那一套，头像是个我不认识的中年男人。

那一刻我才明白，买号的难处不在付款，在登进去之后的头一小时。付款、取号、18 秒推送这些流程在 [TG账号商城](https://tlgrbt-hao.com) 的订单页里写得清清楚楚，用不着谁复述；真正没人告诉新手的是——号到手时它像一张白纸，而白纸上已经写满了别人的笔迹。下面这条时间轴是我后来重做一遍的版本，0 到 60 分钟，九个动作，顺序不能乱。

## 0–5 分钟：先看「设备」，别急着点头像

绝大多数人登进去第一件事是改密码。顺序反了。

打开 **设置 → 隐私和安全 → 设备**（英文界面叫 Active Sessions），这一页列出所有还在登录状态的会话，每条带设备型号、大致地点、最近活跃时间。我在那批号上看到的是：一台 iPhone、一台「Telegram Desktop」、地点跟我对不上、活跃时间是我拿到号之前的几个小时。

先把右上角的 **终止所有其他会话**（Terminate All Other Sessions）点掉，再动密码。理由很实在：旧会话只要还在线，你在 A 端改的东西，对面 B 端可能看得见；有些批量号交付时装的是 tdata 目录包，卖家的电脑上还留着登录态。

这一步有个坑，新号连续操作容易撞限流，页面会弹「请求过于频繁，请稍后再试」，接口层对应 `FLOOD_WAIT_X`，意思是等 X 秒再来。别连点。

## 5–15 分钟：两步验证的四个字段，一个都别留空

设备清干净，接着处理 **设置 → 隐私和安全 → 两步验证**。成品号商品页写的「已激活双因素，含一年账号保险」，这个双因素通常确实开着——但密码是卖家的，有些号的恢复邮箱还指向一个陌生地址。

这一页四个字段：**密码**、**确认密码**、**密码提示**、**恢复邮箱**。

- 密码：单独给这个号设一串，别用你常用的那个。提示语随便写，反正只有你自己看得懂。
- 恢复邮箱：换成你能收信的邮箱。这是整页最值钱的一格，以后忘密码、换设备、被风控拦下，全靠它。
- 旧密码不给怎么办：点「忘记密码」，Telegram 往恢复邮箱发码；那个邮箱不是你的，重置要**等满 7 天**。这七天里，号基本处在半瘫状态。

顺手再看一眼 **设置 → 隐私和安全 → 登录邮箱**，留的是不是自己的地址。

## 15–30 分钟：三处开关，决定别人能不能把你拽进群

开篇那五个群，根因就在这一页。Telegram 默认允许「所有人」把你加进群组，不需要你同意，对方一拉，你就进去了。

| 设置项 | 路径 | 出厂默认 | 我改成 |
| --- | --- | --- | --- |
| 谁能把我加进群组 | 隐私和安全 → 群组和频道 → 谁能把我加进群组 | 所有人 | 我的联系人 |
| 谁可以通过手机号找到我 | 隐私和安全 → 电话号码 → 谁可以通过号码找到我 | 所有人 | 我的联系人 |
| 谁能看到我的手机号 | 隐私和安全 → 电话号码 → 谁能看到我的电话号码 | 我的联系人 | 没有人 |
| 新对话存档并静音 | 设置 → 高级 → 存档和静音新对话 | 关 | 开 |
| 自动删除消息 | 隐私和安全 → 自动删除消息 | 关 | 7 天 |

第一行是重点。改成「我的联系人」之后，非联系人只能发一条邀请链接，你点进去、按下「加入」，才真的进群。第二、三行是配套动作：号码看不见、搜不到，营销号手里那份号码清单就废掉一半。

「自动删除消息」要想清楚，它双向生效，你跟别人的正常聊天记录也会一起消失。做短期项目用的号可以开，长期自用的号先关着更稳。

## 30–45 分钟：清场，一次清到底

设置改完，画面里还堆着旧痕迹，得手动抹。

1. 点开每个陌生群，右上角菜单里选 **退出群组**；频道选 **退出频道**。公开群退出即生效，不用跟谁打招呼。
2. 找到把你拉进去的那个人，点头像，先 **屏蔽用户**，再补一个 **举报垃圾信息**。这一步会让 Telegram 记住这类行为，对后续推荐有影响。
3. **设置 → 用户名**，5–32 位字符。新号建议先留空，或者改成跟手机号、昵称毫无关系的一串。拿手机号当用户名，等于把号码写在自家门牌上。
4. 换头像、改昵称。不少买家的新号顶着一张陌生人的脸用了一个月，自己都没觉得别扭。
5. 清空残留联系人：通讯录里不认识的逐条删掉，那可能是上一任使用者留下的东西。

## 45–60 分钟：用三个动作验证设置真的生效

改完不等于生效，得验。三个动作，十分钟够。

- 让朋友（或你另一个号）试着把你拉进某个群，应该提示无法直接添加，只能发邀请链接。
- 在搜索框输入你的手机号，应该搜不到人。
- 换一台没登录过的设备，用手机号登这个号，应该先要两步验证密码，再往你的恢复邮箱发码。两关都过，说明控制权确实在你手里。

再补一个日常动作：给真实联系人发一条普通消息，确认收发正常。别群发，别把同一段话复制给十个人，新号最怕这个。

操作过密还会撞限流。退群、拉黑、改资料挤在半小时里做完，账号偶尔弹「请求过于频繁」，等 1–2 小时再动手，这一步不用麻烦售后。

## 60 分钟之后：这份清单存下来，换号直接复用

九个动作，按顺序过一遍，下次拿到号照着点：

1. 设备页终止所有其他会话；
2. 改两步验证密码，提示语写成只有自己懂的；
3. 恢复邮箱换成自己的；
4. 「谁能把我加进群组」改成「我的联系人」；
5. 「谁可以通过手机号找到我」关掉；
6. 手机号可见性设为「没有人」；
7. 退掉陌生群、屏蔽拉你的人；
8. 用户名留空或换掉；
9. 换头像昵称、清空残留联系人。

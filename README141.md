# 手机上收藏的 80 多首歌，电脑版登录后一首没出现：汽水音乐登录方式怎么选、多端同步卡在哪一步（附 8 行排查表）

上周去同事家帮他收拾电脑，顺手把汽水音乐也打开。他在手机上收藏了八十多首歌，两天一首首攒出来的，电脑版登录完点开"收藏"，页面干干净净，一首都没有。他先怀疑软件装坏了，接着怀疑"是不是得开会员才给同步"，手指已经悬在客服按钮上。我把他的手机拿过来看了一眼——手机端登的是手机号，电脑上扫码用的是另一个抖音号。两个账号，两份收藏，能对上才怪。

这类"歌不见了"的事，绝大部分跟软件本身没关系，卡在**汽水音乐登录**用错了身份。登录方式和同步规则理清楚，同样的疑问十分钟能自己解决。下面写的路径和开关，官方在 [汽水音乐账号与多端同步说明](https://7cafe-minigame.com) 里也列了，我按实际界面走一遍，顺便把踩过的坑标出来。

## 一、登录进去的是账号，不是这台设备

汽水音乐有三个进门口子：手机号收验证码、第三方账号授权（抖音为主）、电脑版扫码。三种都能进，但**进去的是可能互不相通的账户空间**。手机号注册的号，和抖音授权出来的号，在没做绑定之前是两份独立数据，收藏、歌单、播放历史各存一份，谁也看不见谁。

确认自己手上到底是几个号：手机端进"我的"，点右上角齿轮进设置，找"账号与安全"。那一页会显示当前绑定的手机号（中间打星号）、绑定的第三方账号，还有一串账号 ID。抖音那一栏空着，说明这个号没连抖音，电脑上扫码等于又开了一个新身份。

同一页往下有"绑定抖音账号"，绑完再回电脑版扫码，两边才是同一份数据。顺序别反过来：先绑，后扫。反过来做你会先得到一个空账号，然后盯着它和手机对不上。

## 二、三种登录方式，各自卡在哪儿

| 登录方式 | 入口在哪 | 适合什么情况 | 最容易卡的地方 |
| --- | --- | --- | --- |
| 手机号 + 短信验证码 | 登录页第一栏，填号后点"获取验证码" | 主力账号，换机、重装后恢复收藏 | 验证码约 60 秒失效，超时提示"验证码错误或已过期"；换了号码却没换绑，旧号收不到码 |
| 第三方账号授权（抖音） | 登录页下方的圆形图标 | 收藏主要来自短视频的人 | 授权页显示的昵称头像属于另一个号，看着像同一个，其实是新身份 |
| 电脑版扫码 | 电脑版登录页右侧二维码，手机端"我的"→右上角扫一扫 | 不想在电脑上敲手机号 | 二维码约两分钟过期，页面不会主动提示；手机端本身没登录时扫不出结果 |

第三个方式最省事，也最容易出事：扫码之后电脑端显示的是"扫码那个号"的数据。如果手机端当时登的是抖音身份、而你习惯用手机号找收藏，扫完就会看到一片空白。

## 三、同步机制：哪些跟着账号走，哪些只在本机

把分类搞清楚，很多"同步失败"的疑问自己就散了。

**跟着账号走的（云端）**：收藏的歌曲、自建歌单及其排序、关注的歌手、部分播放历史、抖音音乐收藏同步过来的结果。

**只在本机的**：已经下载的离线文件、播放缓存、音量、音质档位、播放模式、定时关闭设置。换设备之后这些不会跟过来，需要重设，这是设计如此，不是丢了。

**单向流动的**：抖音音乐收藏是"从抖音拉进汽水"，不是双向镜像。你在汽水里取消收藏，抖音那边的收藏不会跟着消失。

同步本身也不是实时的。改完收藏，另一端通常几十秒到几分钟才出现；一口气连改几十首时更慢。刚收藏完就切到电脑上看，看不到很正常。

## 四、8 行排查表：照症状对

| 症状 | 最可能的原因 | 先动哪一步 |
| --- | --- | --- |
| 电脑收藏页全空，手机正常 | 两端不是同一个账号 | 打开两端"账号与安全"，比对账号 ID 与手机号尾号 |
| 只有最近新加的歌没过来 | 同步还没跑完，或网络被判为异常 | 等五分钟，切到同一 Wi-Fi 再刷新一次 |
| 抖音里收藏的歌曲一首没进来 | "同步抖音音乐收藏"开关没开 | 手机端 设置 → 账号与安全 → 打开该开关，回列表下拉刷新 |
| 歌单名字在，里面的歌少了 | 部分曲目在该端不可播，被自动隐藏 | 检查列表是否隐藏了不可播曲目 |
| 提示"登录状态已失效，请重新登录" | 同账号在线设备过多，最早的被挤下线 | 设置 → 登录设备管理，清掉不用的设备再登 |
| 扫码后提示"网络异常，请检查网络后重试" | 公司网络或代理拦了长连接 | 换手机热点试一次，能通就是网络问题 |
| 收藏显示了，点开却要重新加载 | 只有列表同步，音频文件仍在本机缓存 | 属正常现象，重新播放即可 |
| 两端歌单排序不一样 | 排序字段没同步，歌曲本身没丢 | 在电脑端拖一次顺序，回手机端确认 |

## 五、我自己的排查顺序：从最便宜的检查开始

1. 两端各进一次"账号与安全"，把账号 ID 末四位和绑定手机号尾号对一遍。不一致就别往下查了，先统一登录方式。
2. 电脑版在收藏页按 `Ctrl + R` 强制重载一次（电脑版是网页容器，普通刷新用的往往还是缓存）。顺手按空格暂停再播放，能看出播放状态到底有没有连上云端。
3. 手机端 设置 → 账号与安全，确认"同步抖音音乐收藏"是开着的。关掉再打开一次，等于手动触发一轮拉取。
4. 两端连同一个 Wi-Fi。公司网络、公共热点经常拦长连接，症状就是"能刷出列表，但状态不更新"。
5. 设置 → 关于 → 检查更新，把版本落后太多的那一端升上去。老版本撞上新接口，表现就是同步一直转圈。
6. 退出登录再登一次，别卸载。卸载会连本机缓存一起清掉，排查时反而多一个变量。
7. 到这一步还不对，把账号 ID 记下来去找客服，比反复重装有效率得多。

## 六、三个不太有人提的细节

**在线设备是有上限的**。同一账号登得太多，最早那台会被挤下线，提示"登录状态已失效，请重新登录"。家里手机、平板、公司电脑、家里电脑轮着登，很容易撞上。定期进"登录设备管理"里清一遍。

**换手机号之前先换绑**。收藏跟的是账号，不是那张卡；号码被回收之后，带来的麻烦比丢几首歌严重得多。

**公用电脑别勾"记住登录"**。收藏、歌单、播放历史在登录之后是全量可见的，跟私人日记差不多。

这些路径在不同版本里可能挪位置，官方教程按"下载安装 → 播放设置 → 歌单管理 → 个性推荐 → 常见问题"分了类，找不到入口时可以对着 [分主题的汽水音乐教程目录](https://7cafe-minigame.com) 翻。

# 装了电脑客户端，日常还是开着浏览器页面：Telegram 网页版和桌面端 12 项对照，按场景分派与迁移顺序

三个月前我把 Telegram 桌面客户端装好了，下载目录、开机自启、任务栏图标全配齐。一周后我发现一个挺尴尬的事实：真正收消息、翻频道、找文件的地方，还是 Chrome 里那个一直没关掉的标签页。客户端点开停在登录界面，扫完码我又切回浏览器，装了跟没装一样。

后来我想明白了，这不是懒。网页版和桌面客户端不是"新旧两代"的关系，它们是同一个账号在两处开的两扇门，共用一份聊天记录，谁也替代不了谁的全部。想通这点之后我不再纠结"该用哪个"，而是把活分给各自擅长的部分。这篇就把对照关系、适用场景和迁移顺序摊开讲，入口和网页端两个前端版本的说明可以先对着 [电报网页版使用指南](https://tlgrm-wangyeban1.com) 看一遍再往下读。

## 一、客户端装了不用，原因就三条

第一条，浏览器本来就常开。写文档、查资料、回邮件，标签页一直在那儿，消息来了顺手就点。

第二条，冷启动。客户端从点图标到界面可用要几秒，浏览器里的页面是热着的。

第三条，也是最关键的——两边消息完全一样。既然一样，就没有"必须切过去"的理由，人自然留在更顺手的那个上面。

所以问题不在装没装，在于有没有给两边定分工。下面这张表是我按日常动作整理的，对照着看，比凭感觉选靠谱。

## 二、12 项功能对照

读法很简单：**要"翻旧账"和"存文件"的活归客户端，"随手看一眼"的活归浏览器。** 按这条线分，多数人的纠结当场就没了。

## 三、客户端赢在哪三件事

**离线可读。** 已缓存的历史消息断网也能翻，网页版断网就是一张白纸。开会没网、地铁里没信号，差别一下就出来了。

**文件真的能存住。** 客户端在 设置 → 高级 → 数据与存储 里可以指定下载目录、设缓存上限，文件下完就在盘上，不跟着浏览器缓存被清掉。顺手把缓存上限从默认值调到 2–4 GB，来回翻媒体不会反复重下。

**搜索是全量的。** 网页版搜的是当前会话和最近加载的部分，客户端搜的是本地整库，还能按发送人、按时间段、按文件类型过滤。三年的群聊里找一句话，这个差别很致命。

网页端也有它管用的场景：别人电脑上临时登一次、公司电脑不让装软件、系统崩了只剩浏览器、需要并排开两个号看不同群。这些客户端都给不了。网页端文件上传下载的失败原因，站上有一篇 [文件上传下载排查说明](https://tlgrm-wangyeban1.com) 讲得比较细，卡住时对着查比乱试快。

## 四、迁移顺序：把重心搬到客户端的三步

不用一次搬完，按这个顺序走，中间不会断消息。

1. **先对网络。** 打开客户端 设置 → 高级 → 连接类型，确认代理配置和浏览器里那套一致。不一致的典型表现是网页版能进、客户端一直停在 Connecting…，不少人以为是客户端坏了。
2. **再定目录。** 设置 → 高级 → 数据与存储，把下载路径指到空间够的分区，缓存上限调到 2–4 GB。这一步做完，以后收文件不用每次找"下载到哪了"。
3. **然后搬历史。** 同账号登录后云端记录会自动同步，不需要手动导。要留本地存档再走 设置 → 高级 → 导出 Telegram 数据，格式勾 JSON 和 HTML 各一份，前者给工具读，后者给自己翻。
4. **关掉重复通知。** 客户端的系统通知接管之后，回 Chrome 把站点通知关掉：地址栏左侧的锁图标点开 → 网站设置 → 通知 → 改为"阻止"。不然同一条消息响两次，人会被逼疯。
5. **网页版留一个标签页别删。** 在 设置 → 隐私和安全 → 已登录设备 里能看到它，名字是 Telegram Web 加浏览器名，和客户端的 Telegram Desktop 并存。留着当第二块屏，也方便哪天客户端出问题拿来对照。

## 五、两边表现不一样的几个细节

网页版点下载没反应，多半是浏览器的自动下载被拦了。Chrome 的路径是 设置 → 隐私和安全 → 网站设置 → 更多内容设置 → 自动下载，把站点加进允许列表；点通知不弹，就去同一层的"通知"里确认没被设成"阻止"。

客户端的界面位置和网上老教程对不上，是版本差异：4.x 之后侧栏默认收起来了，很多截图里的宽侧栏得手动展开。网页端同样挑版本，WebA 和 WebK 两个前端对话题和媒体的处理不一样，同一台电脑换个入口，看到的界面可能完全不同。

上传大文件的失败点也不同。2 GB 这个上限是账号层面的，两边一样；但网页版会先撞上浏览器内存，传到一半进度条不动，客户端则会明确报错并让你重试。几百 MB 以上的文件，直接换客户端省事。

## 六、两扇门都留着，把分工写下来

我现在桌面上是这样：客户端常驻，负责通知、文件、搜索和通话；浏览器留一个标签页，负责临时看两眼、开第二个号、以及在别人机器上应急。查会话安全的时候两个名字都认——Telegram Web 和 Telegram Desktop 出现在已登录设备列表里，都要能对上号，[网页端登录与多设备会话说明](https://tlgrm-wangyeban1.com) 里有逐项对照。

真要给个判断标准，就一句：**这件事要不要留下东西。** 要下载文件、要翻三个月前的消息、要归档导出，走客户端；只是看一眼、回一句、转个链接，浏览器更快。

网页版和客户端从来不是二选一。选错的代价不是不能用，是每次都在两个窗口之间来回找——那种浪费一天下来能攒出半小时。把分工定下来之后，我那个"装了不用"的图标，终于开始干活了。

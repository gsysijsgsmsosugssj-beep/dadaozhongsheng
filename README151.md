## 二、认领你的那一支：三问定方向

别按"想买什么"排顺序，按"缺什么"排。问自己三句，走到底只剩一个分支：

```
明天早上打开电脑，第一件要干的事是什么？
├─ 有人等着回话（询盘、客服、报价）→ A 线：权重优先
│   └ 第一单 老号 ×1（¥68）→ 第二单 成品号 ×1 做备份
├─ 消息得铺出去（拉群、私聊、话术测试）→ B 线：量优先
│   └ 第一单 小号 ×10（¥69）→ 第二单 成品号 ×1 当主控
└─ 流程还没跑通（头一次买、没登过）→ C 线：确定性优先
    └ 第一单 成品号 ×1（¥25.9）→ 先跑通一次首登再谈量
```

三条线第一单各不相同，共同点是都**先买能独立跑起来的最小单元**，而不是先凑数量。C 线尤其要认：没登过一次就买二十个小号，是最常见的预算沉没方式——登不上时你分不清是号坏、是网络、还是自己操作错，二十个号一起卡在那儿。

## 六、下单到收号，卡在哪一步看哪一步

流程本身很短：在分类标签里选型 → 加购物车确认规格与数量 → 微信 / 支付宝 / Visa / USDT 付款 → 支付成功即触发取号，18 秒内加密推送到订单页与邮箱。夜间下单一样即时，全天无人值守。

容易卡的地方就几个，按这个顺序排查：

- **切了标签是空的**，页面写着"这个分类下没有匹配的账号"。九成是搜索框还留着上一个词，清掉再切；清掉还空，就是这一栏当期断货。

# 两台电脑都装了被控端，难怪连半天没反应：向日葵控制端与被控端到底装哪个，5 种错装症状一次对完

上周三晚上十点半，老周打电话说他"向日葵装好了，两台都装好了，就是连不上"。我让他把两台屏幕各拍一张发过来——两台主界面上都端端正正挂着一行本机识别码，他左手输右边的码，右手输左边的码，前后试了八遍，弹出来的提示一直是"对方设备不在线"。网络没问题，版本也是同一版，问题出在最根上：两台装的都是被控端，一台在等别人来连，另一台也在等别人来连，谁都没有伸手去拨号。

这类事我一个月能碰上三四回。装向日葵真正容易错的不是"下哪个安装包"，而是"这台机器上该确认哪个身份"。下面把角色、装法、错装症状按顺序捋一遍，中间涉及具体平台差异的地方，我对到 👉 [控制端与被控端的角色说明](https://magnum-quest.com) 上，对着自己那台看更直观。

## 一、"装哪个"是单向问题，先问谁伸手

被控端是接电话的那一头，控制端是拨号的那一头。判断只需要一句话：**你现在坐着的这台，要去看别人的屏幕——它装控制端；那台要被人看的机器——它装被控端。**

Windows 和 macOS 的桌面版安装包通常是同一个程序，装完在界面里既能远控别人、也能被别人远控，所以很多人以为"装一个就全有了"，装完两台都不去确认身份，于是两边都停在"等连接"的状态。移动端不一样，Android 和 iOS 上控制端和客户端是分开的两个 App，装错了连识别码界面都找不到。

## 二、角色对照表：两者界面第一屏就不一样

搞不清自己装的是哪个，最快的办法是看主界面第一屏。

| 对照项 | 控制端（伸手的那台） | 被控端（被伸手的那台） |
| --- | --- | --- |
| 主界面第一屏 | 设备列表 + "输入识别码"输入框 | 本机识别码 + 验证码/访问密码 |
| 手上要握的凭据 | 对方的识别码 + 对方密码 | 自己的识别码和密码，交给对方 |
| 不能停的东西 | 无，随时可退出 | 程序进程、不休眠、网络在线 |
| 系统权限要求 | 基本没有 | Windows 防火墙放行；macOS 要屏幕录制 + 辅助功能 |
| 出错时的表现 | "识别码不存在""连接被拒绝" | 显示在线却连不上，或连上黑屏 |
| 最常见的误装 | 在被控那台上找输入框 | 在控制那台上找自己的识别码 |

同一台机器可以让两种角色并存：家里的台式机既能被公司电脑连进去，也能反过来连公司那台。桌面端本来就是"一个程序、两套入口"，主界面上"设备列表"管的是去连别人，"本机识别码"管的是被别人连。

## 三、两台机器该怎么落地：六步走完

按被控端先、控制端后的顺序，第一次配对基本十分钟内能通。

1. **被控端装完先打开**，抄下主界面那行本机识别码，通常是 9 位数字，分三段显示（形如 123 456 789）。截图转文字容易把 0 认成 O，让对方念一遍更稳。
2. **被控端设固定访问密码**：主界面右上角齿轮 → 安全设置 → 访问密码，改成自己记得住的一串。长期用随机验证码，人一不在就进不去。
3. **被控端打开开机自启**：齿轮 → 常规 → 勾选"开机自动启动"。这条最容易被跳过，机器重启一次，前面配的全白费。
4. **macOS 被控端补权限**：系统设置 → 隐私与安全性 → 屏幕录制、辅助功能，两项各勾选一次向日葵，勾完**退出程序再重开**才生效。少这一步的典型现象是"连上了，屏幕全黑"。
5. **控制端添加设备**：设备列表 → 添加设备 → 填识别码 → 起个认得出来的备注名（"店里设计机"比"DESKTOP-8K2Q"强太多），以后一键直连。
6. **控制端发起连接**：双击设备 → 输密码 → 进画面后按 `Ctrl+Alt+Shift+F` 切全屏；需要给对方按登录界面的组合键，用远程窗口顶部工具栏里的"发送 Ctrl+Alt+Del"。

各平台权限弹窗的位置不太一样，[分平台的安装与首次连接图文指南](https://magnum-quest.com) 是按 Windows、macOS、Android、iOS、Linux、鸿蒙 NEXT 分开写的，照着自己的系统点进去少绕路。

## 四、错装排查表：症状对号，别急着重装

连不上时先别删了重下，按这张表对号，十分钟内能定位。九成的"连不上"都不是软件坏了。

| 症状或报错文案 | 最可能的原因 | 当场怎么确认 |
| --- | --- | --- |
| 一直提示"对方设备不在线"，对方明明开着机 | 两头都是被控端，没有任何一端在发起连接 | 让对面拍主界面：只有识别码、没有输入框，就是装反了 |
| 输完码提示"识别码不存在" | 位数抄错、把设备号当成了识别码、对方已退出程序 | 让对方念屏幕上那串数字重新输 |
| 连接建立后画面全黑 | macOS 缺屏幕录制权限，或被控端开了隐私屏 | 补权限后重启程序；隐私屏在被控端关掉 |
| 能看到画面，鼠标键盘没反应 | 缺辅助功能权限，或被控端设成了"仅查看" | 控制端工具栏把模式切回"控制" |
| 连上几秒就断，反复重连 | 两端版本差得太多、安全软件拦通道、弱网 | 两端都更到较新版本，再看杀软拦截日志 |
| "该设备正在被其他会话占用" | 同一个被控端已被另一台控制端连着 | 让对方看别的电脑上是不是还挂着会话 |

表格里第一行就是老周那种情况，也是最不容易自己想到的：两台都在等，屏幕上没有任何报错说"你装错了"，只有一句含糊的"不在线"，人自然往网络上找原因。

还有一类隐性错装出在手机上。Android 的应用商店里控制端和客户端是两个独立条目，有人把控制端 App 装在那台准备被远程的手机上，翻遍设置也找不到本机识别码——因为它压根不负责被控。iPhone 更直接：iOS 侧只能当控制端，想让手机被远程，这条路本来就不通。

## 五、装对之后，两处设置决定后面顺不顺

**访问密码要固定，但别设成生日。** 识别码是门牌号，密码是门禁口令，两个一起泄露等于把门钥匙递出去。"帮我看看电脑"是最常见的诈骗开场，识别码不要发到群里、不要贴在工位上。

**无人值守要按需开。** 开了它，被控端没人守着也能连进去，服务器巡检、门店看机都靠这个；但它和固定密码叠在一起，就是长期敞开的一扇门。我的习惯是：需要时开，用完就关，密码单独设一串，不和其它账号复用。

被控那台如果放在公共区域，远程时打开隐私屏，屏幕上不显示实际画面，省掉很多解释。

## 六、记住这一句就够了

**先问谁伸手，再问装给谁。** 伸手的那台装控制端，被伸手的那台装被控端；桌面端一个程序两套入口，装完必须各自确认身份；手机端两个 App 分开装，别把控制端装到要被控的手机上。

下次再遇到"两台都装好了却连不上"，先让对方拍一张主界面，看有没有输入框，比查网络、重装系统都快。需要按系统找安装包和分平台步骤，从 👉 [magnum-quest.com 的向日葵下载与使用指南](https://magnum-quest.com) 进去按设备挑就行——入口干净、版本最新，剩下的就是把角色分清这一步做对。

## 二、网络：四个勾，决定你能不能登进去

1. **在你常用的那条线上，先把 t.me 打开一次。** 判据不是"能上网"，是客户端左上角不转圈、频道消息刷得出来。有些线路网页打得开、长连接建不起来，那种最坑——网页看着通，客户端一直 Connecting。
2. **三条线路各试一遍**：家里 WiFi、手机流量、公司网络。公司网常只放 80/443，备用端口被挡的表现就是验证码请求发不出去。
3. **看这条线多少人共用。** 免费节点几百人轮一个出口 IP，能登进去，但发一条消息延迟几十秒。首登时客户端会直接给"稍后再试"，你以为是号坏了，其实是出口太脏。翻一眼 `Settings → Data and Storage → Proxy`，能连不等于干净。
4. **断网重连一次，看它能不能自己恢复。** 新号首登最常卡在 Connecting 那三十秒，这时候别连着点"重发验证码"——重发有次数上限，撞上了只能干等。

验证码这一环最容易被忽略。短信码有效期大概五分钟、只能用一次，你边等外卖边等码，低头再抬头，码就废了。先在设备上把短信权限和通知权限放开，再点"发送验证码"，别让手机把你自己的短信拦在通知栏外面。

## 三、设备：四个勾，决定号能不能落地

1. **系统版本。** 安卓 5.0 以下、iOS 12 以下基本装不上当前版本。先去"关于手机"翻版本号，比装到一半失败快得多。
2. **留够空间。** 至少 300MB，缓存和更新包都算在里面。装到 80% 卡住，八成是空间没了。
3. **能不能装第三方包。** 安卓要在设置里打开"允许安装未知来源应用"；iOS 得用非国区 Apple ID，商店里搜不到是正常现象，不是手机坏了。
4. **指定一台常驻机。** 新号到手 24 小时内最好别掉线，挑一台能一直开着、不随手关机的设备当主用端，比手机平板来回切稳当得多。

报错别硬猜，对一下表：

| 你看到的那句话 | 落在哪一类 | 说明 |
| --- | --- | --- |
| 解析软件包时出现问题 / 应用未安装 | 设备 | 安装包与系统版本不匹配，或存储不足 |
| This version of Telegram is too old | 客户端 | 版本被服务端拒绝，必须更新 |
| PHONE_NUMBER_BANNED | 号码侧 | 号码封禁，属于首登异常，凭订单号走 30 天换号 |
| 一直显示 Connecting… | 网络 | 长连接没建起来，换线路再来 |
| 邮箱里半天没有推送 | 邮箱 | 进了垃圾箱，或地址写错了 |

`PHONE_NUMBER_BANNED` 这条最值钱：它证明问题在号、不在你，30 天质保认的就是这个。

还有一种不报错也不提示的：机器能装、能打开，发消息一直转圈。大多是系统时间跑偏——旧手机的自动校时经常失灵，证书校验过不去。付款前花十秒翻一眼"日期与时间"里的自动同步开没开，比事后翻教程省事。

## 四、客户端：五个勾，别在这上面省事

1. **装官方包。** 安卓包名 `org.telegram.messenger`，装完在"设置 → 关于"里能看到版本号；名字里带"汉化""多开""加速"的改包，登录阶段直接失败的概率很高。
2. **版本别太旧。** 服务端会强制老版本更新，你硬盘里那个躺了半年的安装包留着没用。
3. **电脑端先确认目录可写。** Windows 的登录态落在 `%APPDATA%\Telegram Desktop\tdata`，公司电脑常把这个目录锁死，装完一打开就报错。
4. **给客户端后台权限。** 国产 ROM 的自启动和省电策略会把进程杀掉，验证码弹不出来，你只会看到"等待短信"。
5. **先定主用端。** 手机还是电脑当主端，付款前想清楚；一个号同时挂三四个端，第一天风控涨得最快。

## 五、邮箱：四个勾，换号那天才知道有用

1. **用自己完全掌握的邮箱。** QQ、163、Gmail 都行，别填公司域名邮箱——离职那天，账号凭证跟着一起没了。
2. **结算页那栏邮箱认真填。** 它标着"选填"，但账密会同时推到订单页和这个邮箱，等于白送你第二条取件通道。
3. **顺手翻垃圾箱。** 带账号密码的邮件被判垃圾很常见；付完款三分钟内没看到，先去垃圾箱和"推广"标签里找。
4. **给邮箱本身开二次验证。** 号被盗的路径大多不是 Telegram，是邮箱。

四个勾里最容易漏的就是第四条。邮箱一旦被人接管，登录码、改密链接、设备确认全在对方手里，号再干净也守不住。花两分钟在邮箱设置里开二次验证、顺手看一眼"最近登录设备"，这笔账比质保划算得多。
